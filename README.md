# lets-listen

面向直播的桌面节目工具：本地播放音频/视频，由频谱和自动滚动的歌曲简介构成节目画面。支持内置 RTMP 推流。支持使用foobar2000播放

## 本地运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm start
```

开发模式会自动打开开发者工具：

```powershell
npm run dev
```

运行语法检查：

```powershell
npm run check
```


## foobar2000 音频

软件启动时默认选择 foobar2000 音频模式。默认查找 `D:\Program Files\foobar2000\foobar2000.exe`；其他位置可在直播后台点击“选择 foobar2000 程序”。此模式只接管音频，视频仍由内置播放器播放。切回“内置播放器”即可回退。

需要安装官方 [Beefweb Remote Control 组件](https://www.foobar2000.org/components/view/foo_beefweb)：下载 `.fb2k-component`，在 foobar2000 的“文件 → 首选项 → 组件 → 安装”中选择该文件，按提示重启 foobar2000。确认 Beefweb 在本机 `127.0.0.1:8880` 提供接口；应用只连接这个回环地址，不访问局域网。若安装了组件仍无法连接，检查组件是否启用、端口是否为 8880，以及是否允许播放列表修改。在“文件 → 首选项 → 工具 → Beefweb Remote Control”的 Music directories 中加入歌曲所在文件夹；如果目录列表为空或歌曲不在允许的目录内，Beefweb 会对导入音频返回 HTTP 403。

应用通过 Beefweb 每约 200 毫秒读取播放/暂停、进度与音量，节目界面及后台跟随 foobar2000 中的操作；软件中的控制也会发送给 foobar2000。应用新建专属的单曲播放列表，不清空或覆盖已有的列表，切歌时只替换专属列表中的曲目。若进入模式时 foobar2000 的播放队列已有待播曲目，软件会提示先清空队列，避免歌曲结束后自动播放其他曲目；软件不会擅自清空你的队列。播放期间请勿再向 foobar2000 的播放队列添加曲目。切回内置或退出时只停止属于该专属列表的播放，并尝试移除该列表；不会关闭 foobar2000。Beefweb 不提供频谱采样，频谱使用节目窗口静音解码的同一音频，无法解码时改用动态效果。foobar2000 的声音不会进入内置推流，请用 OBS 捕获foobar音频。




## 保存与导入歌单

在主窗口左侧或直播后台点击“保存歌单”，选择一个 `.json` 文件；以后点击“导入歌单”即可恢复曲目顺序、当前选曲、曲名、作曲、投稿人、曲风、简介及其显隐状态、手动封面。导入会替换当前播放队列；播放进度不属于歌单，不会恢复。

在直播后台的播放队列中，拖动曲目前的把手即可调整顺序。当前歌曲会继续播放；曲目序号和下一首/上一首的顺序会立即更新。保存歌单时会按调整后的顺序写入。

歌曲播放到结尾后会停留在当前曲目并显示暂停，不自动切到下一首。再次按播放会从头重播当前曲目；上一首、下一首仍可手动切换。

歌单保存媒体文件和手动封面的相对路径与原始绝对路径，不复制音视频本体。把歌单和媒体一起移动时会优先使用相对路径；找不到的媒体会在导入确认时提示并跳过，找不到的手动封面会退回媒体内嵌封面（如有）。请在编辑曲目信息后先点击保存，再保存歌单。
